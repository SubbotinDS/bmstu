ГРУППИРОВКА ДЛЯ ОТКЛОНЕНИЙ

Группа для получения МАКСИМАЛЬНОГО тока:

Доля алюминия: минимальная (x_Al = 0.95 — при уменьшении доли ток растет)

Толщина квантовой ямы: (d = 4.017 нм), тк дает больший прирост

Толщина первого барьера: максимальная (d = 3.483 нм)

Толщина второго барьера: минимальная (d = 4.017 нм)

Толщина первого спейсера: минимальная (d = 1.977 нм)

Толщина второго спейсера: максимальная (d = 2.543 нм)

Толщина мезы: максимальная (d_меза = 10.5 мкм)

Группа для получения МИНИМАЛЬНОГО тока:

Доля алюминия: максимальная (x_Al = 1)

Толщина квантовой ямы: номинальная (d = 4.3 нм)

Толщина первого барьера: минимальная (d = 2.917 нм)

Толщина второго барьера: максимальная (d = 4.583 нм)

Толщина первого спейсера: номинальная (d = 2.26 нм)

Толщина второго спейсера: номинальная (d = 2.26 нм)

Толщина мезы: минимальная (d_меза = 9.5 мкм)
